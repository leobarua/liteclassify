Lite Classify

by LeoBar · a lightweight desktop app for object-based land-cover mapping of drone orthomosaics

User manual

Turn a drone orthomosaic into a checked land-cover map

Lite Classify splits an aerial image into objects, describes each one by its colour, texture, shape, height and appearance, helps you find the classes the scene really contains, learns those classes from examples you click, and checks the finished map against an independent sample. This manual walks one real -hectare survey through every step: objects, seven classes, training objects and independently labelled check points.

1Welcome

Lite Classify is a desktop tool for geographic object-based image analysis (GEOBIA) of very-high-resolution drone imagery. It was built to map canopy gaps, restoration patches and land use in tropical landscapes, and it works for any cover types you can recognise by eye in an RGB orthomosaic: canopy, plantations, grass, bare ground, roads, buildings, water.

Lite Classify picks up where Lite Flight leaves off. Plan and fly the survey with Lite Flight, process the photos into an orthomosaic and surface model in your photogrammetry software, then bring both into Lite Classify to map them. It is one self-contained program that runs offline on a single workstation, with no Python, GIS software, account or internet connection needed.

You work through four tabs, left to right. Each tab hands its result to the next.

Computing is the quick part. On the worked example, segmentation and feature measurement for objects ran in minutes on a desktop GPU. Most of your time goes into reviewing groups, labelling examples and checking the result.

2Installing and launching

Coming soon. Lite Classify will be released as free, open-source software under the GNU General Public License v3 (see Part D, 17). The program and its source code are not available for download yet; this page describes how installation will work. For early access, write to ldbarua@gmail.com.

Lite Classify ships as a self-contained Windows program; you do not need Python or any GIS software installed.

  1. Download an installer (available at release). Setup CPU (about 300 MB) runs on any Windows 10/11 PC. Setup GPU (about 1.7 GB) adds NVIDIA CUDA support: much faster segmentation and appearance features on an NVIDIA graphics card. Both work offline once installed.
  2. Run the installer. It installs for your user account, with no administrator rights needed, into %LOCALAPPDATA%\Programs\Lite Classify, and adds a Start-menu shortcut (a desktop shortcut is optional). Installing one edition over the other replaces it. Uninstall from Windows Settings › Apps.
  3. Start Lite Classify from the Start menu. A splash screen shows while the libraries load; the first launch can be slow, later launches are quicker.
  4. Check the console at the bottom of the window. It should say Load an image to begin. Every action the app takes is logged there, including errors.
  5. Check the Segmentation Engine box on Tab 1. If GPU is selectable, an NVIDIA CUDA graphics card was found; segmentation and the DINOv2 appearance features will run on it. If it is greyed out, everything runs on the CPU, just slower.
Running from source instead

Once the source is published: clone the repository, create a Python 3.13 environment (python -m venv .venv), run pip install -r requirements.txt, then python liteclassify.py. The requirements pull the CUDA 12.4 build of PyTorch; on a machine without an NVIDIA GPU, follow the note at the top of requirements.txt. The DINOv2 weights (dinov2_vits14_pretrain.pth, about 85 MB) are downloaded once on first use, or read from a models folder beside the code. Close the app before upgrading packages: Windows locks loaded libraries.

3The worked example

Every figure and number in this manual comes from one drone survey: a ha mixed-use block in Bay, Laguna, on the eastern side of the Mount Makiling range in the Philippines. In one flight it holds the cover types an operational workflow has to separate: closed natural canopy; agroforestry stands of coconut, banana and fruit trees; grass and regrowth on disturbed ground; bare soil on tracks and earthworks; a small stream; roads and buildings; and a solid-waste disposal site with its cleared apron.

Objects

The orthomosaic was captured at 3.3 cm per pixel. The worked example segments it on a 10 cm working grid, so objects stay crown-sized, but measures each object's colour and texture from the full 3.3 cm pixels (Part B, 5.3). The DSM comes from the same photogrammetry run on a coarser grid; Lite Classify places it by its coordinates, so the two need not share a pixel size.

The imagery is from a privately owned site and is not bundled with the program. You can follow every step on your own orthomosaic.

4A tour of the interface

The window has a menu bar, four tabs, a control column on the left of each tab, a large map viewer, and a console strip along the bottom that logs every step. All four viewers share one copy of the image, so switching tabs is instant even on large mosaics, and they share the zoom and pan: switching tabs keeps the same view. The bar above each map shows the image's native and working resolution, size, coordinate system and bit depth; below that, the map coordinates under the cursor.

The four tabs

Tab 1

Load, View & Segment

Orthomosaic and DSM paths, resampling, colour correction, the SLIC settings (with Colour/texture at for measuring finer than the segmentation grid), the engine, Run Segmentation, and boundary and elevation overlays.

Tab 2

Discover Classes

Find Groups, a list of group cards, a scrolling gallery of the selected group's tiles, naming, merge, split, ignore and find-similar tools, a group overlay on the map, and Send Named Groups to Classification.

Tab 3

Classification

Class list, the views (Blend, Segmented, Raw/Classified), selection, grow and merge tools, Check Class Separability, What to Label Next, Train and Classify, the minimum mapping unit, and export.

Tab 4

Accuracy Assessment

Reference source, sampling design (simple random or stratified by map class), the point list and assignment tools, Run Accuracy Assessment, and the Iterations list of earlier runs.

Each tab is described control by control in Part C.
