11Workspaces, outputs and file formats

The workspace folder

Each orthomosaic gets its own workspace folder, named after the image and placed beside it. Everything is in open formats, so a session can be audited or continued in any GIS.

Appearance features and groups carry a fingerprint of the segmentation that produced them; Lite Classify never applies them to a different segmentation.

Reopening a workspace

  • File › Load Workspace (Ctrl+O): pick the workspace folder. Lite Classify reopens the recorded orthomosaic and DSM straight at the saved resolution, then restores segments, features, groups, classes, samples, the map, points and iterations.
  • If files have moved, Lite Classify asks you to locate them.
  • Save Workspace As copies the imagery and the workspace to a new folder, for a backup or to hand a project to someone else.

Reset and Return to Loading on Tab 4 clears the session in memory and returns to Tab 1. It does not delete anything on disk.

Fixed settings

Random Forest: 100 trees, scikit-learn defaults otherwise, fixed seed (42). DINOv2: ViT-S/14, frozen; patches of 5 m and 10 m resized to 224 px; 32 principal components per patch size for Discover, 10 for the classifier. Height above ground: ground from a 40 m opening of the DSM at ~1 m. GLCM: 15 grey levels, distance 1, four directions.

14Known limits

  • RGB only. There is no near-infrared band, so no NDVI. Visible-light indices, texture, height and learned appearance do that job.
  • One scene at a time. A model trained on one flight is not automatically valid for another; light and season change colours. Retrain per flight.
  • Linear and tiny features. Features only a few segments wide (streams, footpaths) are under-mapped at a grid chosen for canopy.
  • Segmentation is parameter- and engine-sensitive. Record the values and engine (saved in session.json) and report the realised segment count. GPU runs are not bit-for-bit repeatable.
  • Height above ground under closed canopy. The DSM-only ground estimate rides up under canopy wider than 40 m, so heights there are underestimated.
  • Separability saturates with many features and few samples; it ranks risks rather than proving separability.
  • Photo-interpreted reference is not ground truth. Report it as reference data.

15Glossary

Adjacency graphThe list of which segments share a border. Used by the grow tool, merging and the neighbour features.
Area-weighted estimateAn accuracy or area figure in which each stratum counts by its share of the mapped area, not its share of points.
CIELABA colour space in which equal distances look like equal colour differences. SLIC clusters in it.
CNNConvolutional neural network: an image model built from stacked sliding filters. Lite Classify does not use one; DINOv2 is a vision transformer.
Confusion matrixA table of map class (rows) against reference class (columns) for a set of points. Also called an error matrix.
DINOv2A vision transformer from Meta AI trained without labels. Lite Classify uses it frozen to describe each object's appearance.
DSMDigital Surface Model: height of the top surface, including trees and roofs. Not the bare ground.
EmbeddingA list of numbers describing an image patch, arranged so that similar-looking patches get similar numbers.
FeatureOne measured property of a segment, such as mean green or slope. Lite Classify uses 19, 24 with a DSM, 44 with appearance.
GLCMGrey-level co-occurrence matrix: a tally of how often grey levels sit next to each other. The source of the texture features.
GSDGround sample distance: the ground width of one pixel, e.g. 3.3 cm.
Height above groundDSM height minus a ground surface estimated from the DSM.
JM distanceJeffries–Matusita distance: how separable two classes' samples are, from 0 (identical) to 2 (distinct).
k-meansA clustering method that splits items into k groups around their means. Used by Discover (and, locally, by SLIC).
MMUMinimum mapping unit: the smallest patch the map keeps. Set by the sieve.
OBIA / GEOBIA(Geographic) object-based image analysis: classifying groups of pixels (objects) rather than single pixels.
OrthomosaicA geometrically corrected mosaic of drone photos, with map coordinates.
Overall accuracyShare of the map labelled correctly, estimated from the reference sample.
PCAPrincipal component analysis: compresses many correlated numbers into a few that keep most of their variation.
Producer's accuracyFor one class: share of its real area the map found. Measures omission.
Random ForestA classifier made of many decision trees, each trained on a random resample, that vote.
Reference dataLabels used to check a map. Photo-interpreted reference is distinct from field-verified ground truth.
Segment / objectA connected group of similar pixels produced by segmentation. The unit Lite Classify classifies.
SieveA filter that absorbs patches below a size into their surroundings.
SLICSimple Linear Iterative Clustering: the segmentation algorithm Lite Classify uses.
Stratified samplePoints drawn separately within each stratum (here, each map class) so small classes get enough points.
Training sampleA segment you labelled to teach the classifier.
User's accuracyFor one class: share of what the map calls that class that really is it. Measures commission.
Vision transformer (ViT)An image model that cuts a picture into tiles and relates every tile to every other with attention.
WebODMFree, open-source photogrammetry software from OpenDroneMap that turns drone photos into orthomosaics and surface models. Lite Classify can send it photos; it is installed separately.
